# 🎬 Agent Montage

Logiciel de montage vidéo pour Windows, piloté par un monteur IA (Claude).

Tu lui donnes des instructions comme à un monteur : il regarde tes rushs, coupe et assemble. Il crée aussi des animations, ajoute titres, bruitages et musique, puis te livre un rendu MP4. Tu peux reprendre la main sur la timeline à tout moment.

## Installer

Télécharge `Agent-Montage-Setup-x.y.z.exe` dans la dernière version de l'onglet [**Releases**](../../releases/latest), puis lance-le.

- Windows 10/11, 64 bits. Il faut un compte Claude payant (Pro, Max…) ou une clé API Anthropic.
- L'installateur n'est pas signé. Si Windows SmartScreen s'affiche, clique sur « Informations complémentaires », puis « Exécuter quand même ».
- Les mises à jour se font depuis l'appli : un bouton **⬆ Mise à jour** apparaît quand une nouvelle version est disponible.

Ce dépôt ne contient que les installateurs publiés.
